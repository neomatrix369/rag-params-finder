Security & Operations

Authentication & Encryption

  • Self-hosted: Optional AUTH (requirepass) or ACL users; TLS optional
  • Managed (Redis Cloud): ACL enforced by default; TLS required (rediss://)
  • Slice 53 obligation: Mask credentials in logs; support both redis:// and rediss:// URIs

Persistence

  • AOF (Append-Only File): Log all writes; safe but slower writes. Recommended for production.
  • RDB (Snapshot): Periodic point-in-time snapshots; faster but can lose recent writes on crash.
  • Slice 53 preflight: Warns if AOF is off (vectors are re-creatable by re-running, but slow).

Eviction Policy

  • noeviction (default): Reject writes when memory limit hit. Safest for vectors.
  • volatile-lru: Evict keys with TTL when limit hit. Risky for vectors if misconfigured (vectors must stay TTL = -1).
  • Slice 54 decision (embedding cache): Option (a) one instance with volatile-lru vs. Option (b) two instances (one noeviction, one volatile-lru).

TTL Isolation (Critical Guard)

⚠️ Mutation guard required: Vector keys must never expire (TTL = -1). Slice 53 must prevent EXPIRE on vector keys or risk silent eviction under volatile-lru policy.
